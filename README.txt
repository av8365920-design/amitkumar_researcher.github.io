# Amit Kumar — Academic Website

## Run locally
1. Keep `index.html`, `style.css`, `script.js`, and the `assets` folder together.
2. Double-click `index.html` to open the site in Chrome/Edge.
3. For editing, open the whole folder in VS Code.

## Important customizations
- Replace the `#` links in the LinkedIn and Google Scholar buttons in `index.html`.
- Replace/add publication links if you have DOI or publisher URLs.
- Replace the profile photo at `assets/amit-kumar.jpg` if you want another image.
- Update text whenever your position/publications change.

## Publish online
You can upload this folder to a static hosting service such as GitHub Pages or Netlify.
